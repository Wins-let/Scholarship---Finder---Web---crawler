# Scholarship Finder Web Crawler and Search Engine

## Project Overview

The Scholarship Finder Web Crawler and Search Engine is a web based system designed to automatically collect scholarship information from trusted websites, store the extracted data in a database and provide students with a searchable platform for finding scholarship opportunities.

## Project Objectives

- Automatically crawl scholarship websites.
- Extract relevant scholarship information.
- Store scholarship records in a database.
- Provide a searchable interface for students.
- Allow administrators to manage crawling activities.
